GitHub Pages 更新方法
1. このフォルダ内の index.html / style.css / images フォルダを、現在の swimmy-website リポジトリへアップロードしてください。
2. 同名ファイルは置き換え、images 内の新しい画像もすべて追加してください。
3. Commit changes を押します。GitHub Pages の反映には少し時間がかかる場合があります。
